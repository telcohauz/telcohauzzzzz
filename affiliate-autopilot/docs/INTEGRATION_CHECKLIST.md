# Integration and commercial readiness checklist

All live integrations below are currently disabled/unverified. None of these boxes was inferred from a public platform website.

- [ ] Official Malaysia program terms obtained with URL and review timestamp
- [ ] Official age threshold and eligible country independently verified
- [ ] Account holder meets requirements; no identity substitution
- [ ] Approved affiliate enrollment and payment eligibility verified
- [ ] Owner explicitly approves that account connection and sensitive activation
- [ ] Official permitted product/report/publishing interface verified
- [ ] Export provenance and stable IDs validated against the real account
- [ ] Permitted affiliate disclosure wording reviewed in ms/en
- [ ] Asset and font rights reviewed; no third-party copyrighted media reused
- [ ] New notification destination explicitly approved and delivery tested
- [ ] Durable cloud service active with current applicable free-tier quotas verified
- [ ] No chargeable API, paid plan, trial or overage enabled
- [ ] Staging auth, rate limits, persistence, backup restore and quota tests pass
- [ ] Real publication evidence reconciles with official platform status
- [ ] Financial source reports match actual payouts and costs
- [ ] Paid/unpaid commission allocation and reconciliation implemented/tested
- [ ] Production release URL, commit, deployment ID and health evidence recorded
- [ ] Scheduled cloud jobs observed successfully; idempotency verified live

Adapters are import/manual-publication only. There is no scraping, authenticated browser automation, fake traffic or purchase simulation. Test fixtures are synthetic and never earnings evidence. Other programs require a new reviewed adapter and explicit enrollment verification; no unrestricted generic API is assumed.
